
# 📊 Simulador de Investimento em Fundos Imobiliários (FIIs)



## 📌 Visão Geral do Projeto

Este projeto consiste em uma planilha interativa desenvolvida no Microsoft Excel para simular investimentos em **Fundos Imobiliários (FIIs)**. O objetivo principal é auxiliar o investidor no planejamento financeiro de longo prazo, permitindo:

1. **Cálculo da capacidade de aporte mensal** com base na renda pessoal.
2. **Projeção de acúmulo de patrimônio e proventos mensais** (dividendos) ao longo dos anos.
3. **Análise de cenários temporais** (2, 5, 10, 20 e 30 anos).
4. **Alocação estratégica de carteira por perfil de risco** (Conservador, Moderado e Agressivo) utilizando regras e buscas dinâmicas em matrizes de dados.
